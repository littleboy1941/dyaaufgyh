# AGENTS.md — AyuGram iOS

Форк официального Telegram-iOS 12.9.2 с фичами AyuGram. Задачи ставит Claude (Claude Code), ты (Codex) делаешь исследование, черновой код и ревью.

Перед работой прочитай `ayu-docs/PROJECT_NOTES.md`: там состояние проекта, сборка, сделанные фичи и план. Разбор фич AyuGram лежит в `ayu-docs/ayugram-features-research.md`.

Корневой `CLAUDE.md` — от upstream Telegram (сборка на Mac), к нашему процессу не относится.

## Правила

- Локальной сборки нет: Windows, собирается только на GitHub Actions. Поэтому все API, сигнатуры и типы сверяй с кодом в репозитории, ничего не выдумывай. Если не уверен — пиши «не проверено».
- В git не пиши: коммиты, ветки и push делает Claude. Меняй только файлы, названные в задаче.
- Не трогай `.github/workflows`, `build-system/sideload`, секреты и `.bazelrc`, если задача явно этого не просит.
- Bundle ID `com.ayugram.client` не менять.
- Новый публичный API в `TelegramCore` (public-типы и методы) пересобирает почти всё приложение (~1 час CI). Если можно, решай внутри функций или на стороне UI; если нельзя, скажи об этом явно.
- Свой код помечай префиксом `Ayu` (типы, файлы), чтобы его было легко найти при обновлении upstream.
- Референсы (read-only, shallow-клоны) в `C:\ayu-ref`:
  - `AyuGramDesktop` — актуальный, C++;
  - `AyuGram4A` — Android до 2023;
  - `ghostgram` — iOS-форк 12.2.3, GPL-2.0.
- Отвечай на русском. В конце перечисли изменённые файлы, объясни решения и риски.
